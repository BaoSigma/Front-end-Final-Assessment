# Sales Analytics Dashboard

A modern sales analytics dashboard built with Next.js 15, TypeScript, and Tailwind CSS, implementing atomic design principles.

## 🚀 Features

- **Atomic Design Architecture**: Well-structured component hierarchy (Atoms → Molecules → Organisms → Templates)
- **Interactive Charts**: Multiple chart types (Bar, Line, Pie) using Recharts
- **Custom Filtering**: Sales threshold filter for data visualization
- **Responsive Design**: Fully responsive layout with Tailwind CSS
- **Type Safety**: Full TypeScript implementation
- **Mock Data**: Realistic sales data spanning 2022-2024
